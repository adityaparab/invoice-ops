# Golden corpus v1.0.1

The [dataset design and reproduction instructions](../../docs/EVALUATION.md)
describe the committed manifest and ERP snapshot in `v1.0.1/`. Its images,
splits, and ERP data match v1.0.0; the Voxel51 gross row amounts are no longer
mislabelled as net line totals. Document bytes are generated in ignored
`eval/data/golden/v1.0.1/`; no model credentials or real invoice data are used
by the builder.
